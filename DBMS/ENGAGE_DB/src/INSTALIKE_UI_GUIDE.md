# ENGAGE V8.1 UI Guide

The public pages behave like a social application: Home feed, stories, Explore, Activity, Messages, Profile, Insights and recommendations.

The **Studio** page is an optional in-app data/analytics view. The formal DBMS query demonstration should be done directly in PostgreSQL using pgAdmin or psql.

Recommended navigation for the demo:

Home → Like/Comment/Follow → For You → Insights → PostgreSQL/pgAdmin → run `POSTGRES_DEMO_QUERIES.sql`.

All of these pages use the same PostgreSQL database.
